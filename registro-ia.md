Registro do uso da Inteligência Artificial
1. Ferramenta utilizada

Durante a realização deste trabalho, utilizamos o ChatGPT, uma ferramenta de inteligência artificial desenvolvida pela OpenAI, como apoio à pesquisa, organização e produção da cartilha sobre o GitHub.

2. Objetivo da utilização da IA

A inteligência artificial foi utilizada para:

Compreender os conceitos básicos do GitHub.
Diferenciar Git e GitHub.
Aprender sobre repositórios, README e Markdown.
Entender o funcionamento de commits, branches, pull requests e merge.
Organizar as informações da cartilha.
Melhorar a clareza dos textos e das explicações.
3. Prompts utilizados

Prompt 1:

"Somos estudantes iniciantes e precisamos produzir uma cartilha sobre GitHub. Explique o que é Git, GitHub, repositório, README, Markdown e commit com exemplos simples."

Prompt 2:

"Explique como compartilhar um repositório no GitHub, convidar colaboradores, criar uma branch, abrir um pull request e realizar um merge pelo navegador."

4. Respostas da IA que foram verificadas

A IA explicou que o Git é um sistema de controle de versões e que o GitHub é uma plataforma online utilizada para hospedar projetos e facilitar a colaboração.

Também explicou que:

Repositório é o espaço onde ficam armazenados os arquivos de um projeto.
Commit registra as alterações realizadas.
Branch permite trabalhar em uma versão separada do projeto.
Pull request solicita a revisão de alterações.
Merge incorpora as alterações em outra branch.
5. Como verificamos as informações?

Para conferir as respostas da inteligência artificial, consultamos a documentação oficial do GitHub e realizamos testes diretamente na plataforma, utilizando o navegador.

Verificamos a criação de repositórios, a edição de arquivos, o registro de commits, o compartilhamento com colaboradores e o processo de revisão e merge.

As orientações foram utilizadas somente após a conferência pelos integrantes do grupo.

8. Conclusão

A inteligência artificial ajudou nosso grupo a compreender melhor o GitHub e a organizar as informações da cartilha.

Aprendemos que a IA é uma ferramenta de apoio, mas suas respostas precisam ser conferidas em fontes confiáveis e por meio de testes práticos.

Assim, conseguimos desenvolver o trabalho com mais organização, clareza e conhecimento.
